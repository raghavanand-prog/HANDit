# Security policy

HANDit is maintained by Raghav Anand. It is a public test and has **not been independently security-audited**.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open this repository's **Security** tab and choose **Report a vulnerability**. Only the maintainer can see the report.

Please don't open a public issue for a vulnerability, and don't attach real personal files to a report.

The maintainer aims to reply within 7 days. Confirmed issues are fixed as soon as possible, and reporters are credited in the release notes unless they prefer not to be.

## Scope

- The website and the Worker that serves it
- The introduction server (the Room), the link format and the sealed introduction messages
- The direct transfer, file verification and filename handling

Out of scope: malware on a device, a compromised operating system or browser, and disruption through sheer volume of traffic.

## Supported versions

Only the version currently live at the official URL listed in the README.
